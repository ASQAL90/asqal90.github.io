Proyek

Dua aplikasi, dua masalah sehari-hari.

Ayo Jama'ah!

Jadwal sholat, kalender Hijriyah, widget desktop, dan pengingat teks tanpa suara. Perhitungan dilakukan lokal lewat core Rust, tanpa kirim data ke mana pun.

  • C# / .NET
  • Rust
  • Windows 10/11
Situs Kode Unduh

TileKeeper

Utility tray yang menjalankan ulang program yang tertutup dan mengembalikan jendelanya ke monitor serta cell 3×3 yang sudah ditentukan. Awalnya dibuat untuk layar Andon di tempat kerja.

  • C# / WinForms
  • .NET Framework 4.8
  • Windows 10/11

Yang sama dari keduanya

  • Tidak ada akun, langganan, atau telemetri.
  • Bisa dijalankan dari folder mana saja; installer juga tersedia untuk Ayo Jama'ah!.
  • Dibangun tanpa sertifikat code signing, jadi SmartScreen bisa memberi peringatan pertama kali jalan.
  • Kode sumber terbuka. Ayo Jama'ah! memakai lisensi MIT; TileKeeper juga MIT.
